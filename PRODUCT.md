# PRODUCT.md

## Producto

**MaestroArch / Creador Arquitecto**

## Problema

Crear un producto digital completo normalmente exige coordinar producto, arquitectura, diseño, frontend, backend, QA, seguridad, Git y deploy. Esa coordinación consume tiempo, genera bloqueos y obliga al usuario a tomar demasiadas decisiones técnicas.

## Propuesta de valor

Permitir que una persona describa lo que necesita en lenguaje natural y que el sistema convierta esa intención en un producto digital funcional con mínima intervención humana.

## Usuario inicial

- emprendedores;
- creadores;
- pequeños negocios;
- desarrolladores no expertos;
- equipos que quieren acelerar prototipos y MVPs.

## Promesa del producto

> Decime qué necesitás y Creador Arquitecto lo transforma en un producto funcional, versionado en GitHub y listo para evolucionar.

## Experiencia objetivo

El usuario no administra agentes individuales. Describe una necesidad y ve:

1. entendimiento del problema;
2. definición del MVP;
3. arquitectura elegida;
4. avance de implementación;
5. validaciones;
6. estado del repositorio;
7. siguiente hito.

## Restricciones iniciales

- costo cero o mínimo;
- GitHub como fuente de verdad;
- Vercel como destino principal futuro;
- web primero;
- Android/iOS después del MVP base;
- evitar infraestructura compleja prematura.

## North Star

Reducir al mínimo el tiempo entre:

**Idea → primer producto usable por un usuario real.**
